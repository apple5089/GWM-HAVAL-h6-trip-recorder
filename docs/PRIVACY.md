# 隐私与外发数据

## 本地保存

`data/` 或 Docker 数据卷保存轨迹、采样时间、车辆状态、行程、通知队列和图片。手机号、设备标识、车辆会话、腾讯及 Kimi Key、飞书应用配置和 Webhook 使用 Fernet 加密，主密钥为 `.secrets/master.key`，密文为 `.secrets/account.enc`。

主密钥与密文位于同一主机，用于保护配置文件直接泄漏的情况；取得整个数据卷的人仍可读取配置。请把数据卷、CSV、图片、日志和备份作为私人数据管理。

## 运行时的数据流

| 接收方 | 发送内容 | 触发条件 |
| --- | --- | --- |
| 车辆云端 | 登录信息、会话及状态查询 | 单独接入客户端并由用户登录、采集 |
| 腾讯静态地图 | 地图中心、缩放、尺寸 | PNG 开启道路底图且缓存未命中 |
| 腾讯地名服务 | 起终点、所标停留点坐标 | 启用地名查询且缓存未命中 |
| Kimi | 城市/商圈、地点类别、距离、用时、天气 | 启用标题生成且缓存未命中 |
| Open-Meteo | 经纬度各保留一位小数的粗网格、日期 | 启用天气且缓存未命中 |
| OpenStreetMap 瓦片服务 | 浏览器当前地图视野 | 网页开启道路底图 |
| 飞书 | 配置的文字、轨迹图片、提醒 | 启用通知或用户主动测试、补发 |

Kimi 请求不包含轨迹、精确坐标、详细地址、学校具体名称、车架号或账号。轨迹折线在本机绘制，不作为整段路径发送给静态地图接口。图片通过飞书发送后由目标租户和接收群的访问规则管理。

## 开源仓库中的数据

本仓库只使用合成测试数据和合成展示图。公开文件不包含车主账号、API 密钥、飞书群标识、NAS 地址、真实轨迹、数据库、会话、主密钥、抓包或原始 APK。

`.gitignore` 与 `.dockerignore` 排除运行数据和外部客户端。`tools/check_public_tree.py` 检查公开目录中的常见敏感文件及令牌格式；发布者还应在本地将待发布文件与自己的已知凭据逐项比对，并检查 Git 历史。

## 访问边界

管理页具有查看轨迹和修改设置的权限，默认只监听本机。Host 和 Origin 检查用于约束请求来源，不替代访问身份验证。远程使用时配置受控网络、SSH 隧道或带认证的 HTTPS 代理。
